# RepWise no celular

Abra https://repwise-ai.ynk-victor.chatgpt.site no navegador do celular.

Toque em **Criar conta** e informe nome, e-mail, senha e confirmação. Depois use **Entrar na minha conta** com o mesmo e-mail e senha em qualquer aparelho. O computador não precisa estar ligado. Aguarde “Salvo na sua conta” antes de sair. Ao trocar de aparelho, abra ou recarregue a página para carregar os registros.

Para mostrar à professora sem cadastro, use **Entrar na demonstração**. Os dados desse modo são fictícios e ficam no navegador dela.

É possível adicionar o endereço à tela inicial pelo menu do navegador. O app precisa de internet para entrar e sincronizar. Se a conexão falhar, confira o aviso de alterações pendentes, tente novamente ou exporte o backup pelo Perfil. Limpar os dados do navegador pode apagar alterações ainda não sincronizadas.

O código atualizado fica em C:\Victor Workspace\Analise e Projeto de Sistemas\RepWise_AI. O README descreve desenvolvimento, testes e publicação. A versão 0.5 usa dados em JSON no banco persistente da hospedagem. Ainda não há recuperação de senha nem IA real.
